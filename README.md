# 체리니 바잉 (Cherinee Buying)

일본 현지 바잉(구매대행) 주문과 입금 관리를 위한 모바일 웹앱 프로토타입입니다.
빌드 도구 없이 `index.html` 한 파일로 동작하며, 데이터는 브라우저 LocalStorage에 저장됩니다.

## 화면

- **손님 화면**: 바잉 회차·상품 목록, 옵션 선택, 장바구니, 주문서 제출, 주문내역(입금 전 / 입금 확인 대기 / 입금 완료 / 배송중), 입금 확인 요청
- **사장님 화면**: 주문·입금 관리(전체 / 미입금 / 입금 확인 대기 / 입금 완료 / 손님별 모아보기), 입금 확인·배송 시작, 바잉 회차·상품 등록(사진 첨부·샘플 이미지·재고 수량·빠른 품절), 회원 승인, 시트 내보내기(CSV 다운로드 / 시트용 탭 구분 복사)
- **로그인·가입**: 승인제 회원가입, 승인 대기 화면

## 재고 관리

실시간 바잉이라 수량이 한정적인 상품을 위해 재고를 같이 관리합니다.

- 상품마다 **재고 수량**을 넣을 수 있고, 비워 두면 `무제한`으로 팔립니다. **품절 표시**는 재고가 남아 있어도 바로 켜고 끌 수 있어요.
- 손님 화면 상품 카드·상세·장바구니·주문서에 `남은 3개`처럼 남은 수량이 보이고, 3개 이하면 강조되며 0개면 `품절`로 담기·바로 주문이 막힙니다.
- 장바구니 수량을 늘리거나 주문을 확정할 때 남은 재고를 넘으면 안내 문구가 뜨고 진행되지 않습니다. **주문이 접수되면 재고가 바로 차감**됩니다.
- 사장님이 **주문을 삭제하면 차감됐던 재고가 자동으로 복구**됩니다(수량으로 관리하는 상품만).
- 사장님 → 상품·회차 목록에서 상품별 남은 재고를 보고 `−` `+` `+5` 버튼으로 현장에서 바로 늘리거나 줄일 수 있어요.

상단의 **미리보기** 전환바에서 손님 화면 / 사장님 / 로그인·가입 화면을 오가며 시험할 수 있습니다.

## 체험 계정

| 아이디 | 비밀번호 | 상태 |
| --- | --- | --- |
| `seoyeon` | `1234` | 승인 완료 |
| `haneul` | `1234` | 승인 대기 |

새로 가입 신청하면 ‘승인 대기’가 되고, 사장님 화면 → 회원 → **승인**을 누르면 손님 화면에서 주문할 수 있습니다.

## 참고

- 데모용 데이터이며, 입금 계좌는 예시입니다. 사장님 화면 → 회원 → 설정에서 실제 계좌로 바꿀 수 있습니다.
- 우측 상단 ↺ 버튼으로 데모 데이터를 처음 상태로 되돌릴 수 있습니다.
